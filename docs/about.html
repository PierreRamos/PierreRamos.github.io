Bio

I'm a Unity programmer from Metro Manila, working remotely for a US game studio since 2023.

At Mega Cat Studios I've worked across gameplay systems, UI/UX, animation, save/load, porting and internal tools, for games on PC, PlayStation, Xbox and mobile. These days I focus mostly on UI. My teammates call me the team's Swiss Army knife: if it's code, I'll learn it, and I've filled in on non-programming roles when the team needed cover.

I also make my own art. Pixel art, 2D illustration and UI art let me take a feature from code to finished visuals, and every personal project on this site uses art I drew.
