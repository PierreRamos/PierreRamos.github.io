Pixel Punch

A solo fighting-game prototype in the style of One Finger Death Punch.

Role
Solo: code and art
Engine
Unity, C#
Year
2023
Status
Prototype, back in development

Overview

Pixel Punch is a 2D brawler inspired by One Finger Death Punch: enemies rush in from both sides and every input counts. I wrote all of the code and drew and animated every sprite.

What I built

  • All gameplay logic: player attacks, dash, health and a special meter.
  • Enemy spawning driven by a difficulty manager, with object pooling for enemies and particle effects.
  • Enemy variants, including elites that can't be beaten with a single hit: each one carries nodes, and every node starts its own short minigame the player has to clear to bring it down.
  • A one-on-one hold-battle mode with its own timer and input prompts.
  • Game feel: camera shake, hit indicators and pooled particle effects.
  • An event-driven architecture that keeps player, enemy and UI systems decoupled.

What's next

I'm back to work on Pixel Punch and aiming to take it from prototype to a finished game.
